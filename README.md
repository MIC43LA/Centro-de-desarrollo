
# 🌱 Sistema de Gestión de Stock - Vivero "El Jacarandá"

## 📖 Descripción
Aplicación de escritorio desarrollada para el vivero **El Jacarandá** en Concordia.  
El sistema permite gestionar de forma simple y sin depender de internet el **stock de plantas**, **clientes**, **ventas**, **proveedores** y **encargos especiales**.  

Su objetivo es reemplazar cuadernos y planillas por un sistema confiable, fácil de usar y adaptado al trabajo cotidiano del vivero.

---

## ✨ Funcionalidades principales

### 1. Stock de plantas
- Alta, consulta, modificación y baja de variedades.
- Filtros por sector (interior, exterior, invernadero, huerta) y categoría (árboles, arbustos, suculentas, etc.).
- Búsqueda por nombre común o científico.
- Actualización automática del stock al registrar ventas.

### 2. Clientes
- Registro de clientes con datos de contacto y notas personalizadas.
- Búsqueda por DNI o nombre.
- Historial de compras y encargos vinculados.

### 3. Ventas
- Registro de ventas con detalle de ítems.
- Cálculo automático de totales y formas de pago.
- Descuento automático del stock.
- Modificación y anulación de ventas.

### 4. Proveedores
- Gestión de proveedores con datos de contacto y productos que ofrecen.
- Registro de fecha del último pedido.
- Alta, consulta, modificación y baja.

### 5. Encargos especiales
- Registro de pedidos personalizados vinculados a cliente y proveedor.
- Estados: pedido, llegó, entregado, cancelado.
- Gestión de señas y fechas estimadas de llegada.

---

## 🖥️ Uso del sistema
- Menú principal con acceso a las cinco áreas.
- Navegación simple y validaciones amigables.
- Confirmación antes de eliminar registros.
- Persistencia de datos en listas y diccionarios.

---

## ⚙️ Tecnologías utilizadas
- **Lenguaje:** Python 3
- **Módulos:** `datetime` para manejo de fechas
- **Estructuras de datos:** listas, diccionarios y tuplas
- **Paradigma:** programación modular con funciones claras y separadas
